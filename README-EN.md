# RuangSense-v2 ❄️
> **A Modern IoT Platform & Dashboard for Real-time Environmental Monitoring.**

RuangSense-v2 is a premium web-based IoT dashboard application engineered to monitor indoor environmental conditions (temperature, humidity, and air quality/gas levels) instantly with zero latency. Utilizing a Room-based architecture built on Socket.io, this platform guarantees that data streaming from various microcontroller devices (such as the ESP32) is securely, precisely, and isolatedly delivered to an elegant user interface.

---

## ✨ Key Features

- **Real-time Monitoring & Analytics**: Live sensor data streams straight from the hardware and are visually presented using Recharts smooth curved area charts—no page refreshes required.
- **Multi-device Room Isolation**: Implements a virtual room system (*Socket Rooms*) ensuring that sensor data from a specific device is only broadcast to users explicitly monitoring that hardware instance.
- **Premium Dark Industrial UI**: Features a futuristic, minimalist, and sleek interface with a *glassmorphism* aesthetic powered by Tailwind CSS, paired with smooth micro-interactions from Framer Motion.
- **Real-time Activity Log**: Displays historical sensor data in a reverse chronological order (*descending*), guaranteeing that the latest telemetry is always pinned to the top of the data table.
- **Responsive Layout**: Fully optimized for both desktop monitors and mobile devices, complete with native horizontal scrolling support on dense data table components.

- **Socket.io Server** (Real-time WebSockets Manager)
- **MongoDB** & **Mongoose** (Historical Data Storage & Device Management)
- **Dotenv** (Environment Variable Management)

### Hardware & Peripherals (Simulation/Production)
- **ESP32 Microcontroller** (WiFi Connection Enabled)
- **Sensors**: DHT22 (Temperature & Humidity), MQ-2 / MQ-Series (Air Quality/Smoke/Gas)
- **Communication & Broker**: **MQTT Broker** (e.g., HiveMQ / Mosquitto / EMQX) acting as the central hub for *publish/subscribe* real-time data exchange between the ESP32 and the Backend Server.

## 📐 Real-time Data Flow Architecture

1. **Hardware Layer**: The ESP32 device periodically reads environmental data (such as temperature, humidity, and gas levels) from the sensors.
2. **Network Layer (MQTT)**: The ESP32 sends (publishes) the data payload to an MQTT Broker via the MQTT protocol on a specific topic.
3. **Broker Layer**: The **MQTT Broker** receives the message from the ESP32 and instantly distributes the data to all clients subscribed to that topic.
4. **Backend Layer (Node.js/Express)**: The backend server acts as an MQTT client, subscribing to the relevant topic. When data arrives from the broker, the backend captures it and uses the `io.to(device_id).emit('v2-device-data', payload)` command via Socket.IO to
5. **Frontend Layer (React)**: The browser connected to that room listens for the socket event from the backend and instantly updates the monitoring charts and tables.

## 🚀 Getting Started & Installation

### 1. Clone the Repository

```bash
git clone https://github.com/azkafaza/ruangsense-v2.git
cd ruangsense-v2
```

### 2. Backend Configuration

Navigate to the backend directory, install the required dependencies, and set up your environment configuration.

```bash
cd backend
npm install
```

Create a `.env` file inside the `backend/` directory and configure your variables:

```env
PORT=5000
MONGODB_URI=mongodb://localhost:27017/ruangsense_v2
MQTT_BROKER=mqtt://broker.emqx.io
```

Start the backend server:

```bash
npm run server
# or using nodemon
nodemon server.js
```

### 3. Frontend Configuration

Open a new terminal window, navigate to the frontend directory, and install the dependencies.

```bash
cd frontend
npm install
```

Start the local frontend development server (Vite):

```bash
npm run dev
```

By default, the frontend application will be accessible at `http://localhost:5173`.

### 4. Connecting the ESP32 (Development Phase) via Local-to-Public Deployment

If your backend server is running locally on `localhost:5000`, boot up **ngrok** to open a secure public tunnel using the following command:

```bash
ngrok http 5000
```

Copy the public URL generated by ngrok (e.g., `https://abcd-123.ngrok-free.app`) and paste it into your ESP32 source code (sketch) as the target endpoint for your HTTP POST requests.

## 📝 Sample Sensor Payload Format (JSON)

When the ESP32 posts data to the backend, ensure the incoming JSON payload structured as follows:

```json
{
  "device_id": "Device-ID",
  "temp": 25.5,
  "temp_status": "normal",
  "humid": 55,
  "humid_status": "normal",
  "gas": 42,
  "gas_status": "normal",
  "time": "14:47:25"
}
```
